# Lilac Flower Bar — website

One-page website for **Lilac Flower Bar**, a florist and gift shop in Kazanchis, Addis Ababa (next to Elilly Hotel, in front of ECA).

Plain HTML, CSS and JavaScript, with no build step. Open `index.html` in a browser to preview.

## Files

- `index.html`: page content (hero, services, collection, chocolates, reels, reviews, map, FAQ, footer)
- `styles.css`: design system and layout
- `script.js`: interactions (menu, filters, lightbox, review carousel, reveals)
- `assets/`: logo, product photos, chocolate photos and short video reels
- `PROMPT.md`: the full brief used to build the site

## Before publishing

Search the code for `VERIFY` and confirm: chocolate brands in stock, opening hours, delivery areas and fees, international payment options, and the WhatsApp number.

## Publish free with GitHub Pages

Repository **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**. The site goes live at `https://<username>.github.io/<repository>/` within a minute or two.
